# 🎬 Book My Show – Java/Spring Boot Application

## 📖 Overview
This project is a **Spring Boot application** inspired by the popular *BookMyShow* platform.  
It enables users to browse movies, book tickets, and manage showtimes with a backend system built using **Java, Spring Boot, and PostgreSQL**.  
Designed to practice **backend development, REST API design, and database integration**, it simulates a real-world ticket booking system.

---

## ✨ Features
- 🎥 **Movie & Show Management** – Add, update, and list movies with showtimes.  
- 🪑 **Seat Booking** – Track seat availability and reservations.  
- 👤 **User Accounts** – Registration, login, and authentication.  
- 💳 **Ticket Booking & Cancellation** – Secure and reliable booking flow.  
- 📊 **Admin Panel** – Manage theaters, shows, and halls.  
- 🗄️ **Database Integration** – PostgreSQL for persistent storage.  

---

## 🛠 Tech Stack
- **Java** – Core backend logic  
- **Spring Boot** – REST API framework  
- **PostgreSQL** – Database  
- **Maven** – Dependency management  
- **Postman** – API testing
